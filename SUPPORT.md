# Support

## Where to get help

| Need | Where |
|------|-------|
| Bug / feature | Open a GitHub Issue (templates required; blank issues disabled) |
| Security vulnerability | Private GitHub Security Advisory — see `SECURITY.md` |
| Usage questions | GitHub Issues with the `question` label |
| Deeplink receiver behaviour | [introVRt-Lounge/vrchat-jellyfin](https://github.com/introVRt-Lounge/vrchat-jellyfin) |

This is a **self-hosted Jellyfin plugin** (DLL + optional JS Injector script). There is no hosted SaaS product behind this repo.
